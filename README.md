# Pickleball-Match-Generator

I run a Pickleball League in St. Louis; this is a simple website to generate matches for games.

You can enter names separated by a comma or individually. Players will be added to a list of players, you can then select the number of courts you are playing on and generate matches. This is meant for doubles play, with the teams swapping each game so everyone gets the chance to play with everyone else.

Wins are tracked by player, so each week you can export the list of players and their wins, and at the end of your session count up wins per player.
